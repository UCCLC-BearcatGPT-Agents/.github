# UCCLC BearcatGPT Agents
**Course-aligned tutoring agents for the University of Cincinnati**
UC Clermont Learning Commons
</div>

[BearcatGPT](https://bearcatgpt.uc.edu) · [AI at UC](https://ai.uc.edu/ai-tools/bearcatgpt) · [Learning Commons](https://www.ucclermont.edu/students/ucc-learning-commons.html) · [Studio](https://studio.bearcatgpt.uc.edu)

---

The **UC Clermont Learning Commons (UCCLC)** builds tutoring agents that run on [BearcatGPT](https://bearcatgpt.uc.edu), the University of Cincinnati's private generative AI platform. This GitHub organization is where that agent work is kept.

A student opens the agent for their course. The agent teaches the next step and waits for the student to take it. Instructors set the rules for AI in the class. Sign-in uses a UC account. [UC's BearcatGPT page](https://ai.uc.edu/ai-tools/bearcatgpt) states that information entered on the platform is not used to train external public models.

## The agents students see

**Bearcat Study Pal**, **Bearcat Genius**, and **Bearcat Test Prepper** are the shared student-facing core. Kartavya Singh and Shivam own them together. Course agents are the same pattern, locked to one class and that class's materials.

| Agent                    | Owners | Role                                                                                    |
| ------------------------ | ------ | --------------------------------------------------------------------------------------- |
| **Bearcat Study Pal**    | KS, SH | Stays with the student for the session and keeps the work on the question they brought. |
| **Bearcat Genius**       | KS, SH | Teaches a single step, then checks that the step makes sense before going further.      |
| **Bearcat Test Prepper** | KS, SH | Practice and exam-style work, once the student has a way into the material.             |

Pal keeps the thread. Genius teaches one step. Prepper handles practice. Course agents are prepared with the instructor before students are asked to use them.

In February 2026, UC reported that BearcatGPT tutoring agents were already available in multiple courses, reaching several thousand students, with further courses planned through the academic year ([UC News](https://www.uc.edu/news/articles/2026/02/bearcatgpt-ai-platform-now-available-to-uc-students.html)).

## How a session is meant to go

1. The student signs in at [bearcatgpt.uc.edu](https://bearcatgpt.uc.edu) and opens the agent for the course.
2. The agent asks for one step of reasoning, then waits.
3. Practice comes after the idea is in place.
4. When a chat is no longer the right help, the agent points the student to a person at the Learning Commons.
